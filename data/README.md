# Data

This directory holds the raw `.csv` files used by the seed scripts in the `/scripts` directory to populate the database.

## File Naming Convention

The CSV file name should correspond to the collection it is seeding (e.g., `geographies.csv` seeds the `geographies` collection).

## Column Headers

The column headers in each CSV file **must** match the field names expected by its corresponding seed script. Refer to the script file for the exact required headers.
